# File Organization Practice Scripts

A set of bash scripts for practicing file manipulation and organization in Linux.

## Structure
- `Start/` - This is where the files will initially be created
- `Check/` - Files get moved here to be checked or processed
- `TurnIn/` - Destination folders. This is where the files will end up, organized.

## Usage
1. Run `./SwapMe/create_blank.sh` to create 300 test files
2. Run `./SwapMe/move_files.sh` to move files to Check folder
3. Run `./SwapMe/organize_files.sh` to sort files into categorized folders
4. Run `./SwapMe/cleanup.sh` to remove all files in the TurnIn folder
5. Run `./SwapMe/file_swap.sh` to run all of the files (this may or may not work properly)

All placeholder.txt files in this repo are simply to upload empty files. If downloaded with the project, they will be deleted in the process.

## What it does
Creates 30 files each for 10 categories (report, memo, note, etc.) and demonstrates automated file organization workflows.
